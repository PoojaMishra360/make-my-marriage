# Project instructions

## Keep project progress current

- Use [`doc/PROJECT-STATUS.md`](./doc/PROJECT-STATUS.md) as the project progress record.
- When completing or materially changing a major feature or milestone, update the status file in the same change. Update its current status and add a dated entry to the progress log.
- Record whether a feature is implemented, partially implemented, UI-only, or deferred. Do not describe mock data or design copy as working backend behavior.
- Skip status-log updates for minor refactors, typo fixes, and routine maintenance that do not change project capability or milestone status.
- Before starting substantial feature work, read the status file and the relevant scope/architecture documents under `doc/`.
